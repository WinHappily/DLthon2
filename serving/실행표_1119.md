## 0. 시험 (처음 한 번)

`EXP = "TEST_p2"`, 개발 150, `검색결과_oracle_page_150.jsonl`, `LIMIT = 10`, 모델 하나 → 출력 형식과 잘림(length) 확인.

## 1. 개발 150 (`QUESTIONS = 개발문항_150.jsonl`, `QSET = "dev150v2"`)

| EXP | RETRIEVAL | USE_MEMO | VERSION_FILE | 보는 것 |
|---|---|---|---|---|
| O1u_150 | 검색결과_oracle_pdf_150 | False | None | 모델 실력 (가장 깨끗) |
| O1p_150 | 검색결과_oracle_page_150 | False | None | 쪽 단위로 자른 몫 |
| O1pR_150 | 검색결과_oracle_page_150 | False | 판본_A규칙_150 | 판본을 코드에 맡긴 효과 |
| T2_150 | 검색결과_T2_150 | False | None | 검색 몫 |
| T2M_150 | 검색결과_T2_150 | True | None | 판정 메모 효과 |
| T2MR_150 | 검색결과_T2_150 | True | 판본_A규칙_150 | **최종 시스템 후보** |

## 2. 잡음 90 (`QUESTIONS = 잡음문항_90.jsonl`, `QSET = "noise90"`)

위 표와 같고 파일 이름만 `_잡음_90`, 실험ID 끝만 `_N90`.
- 예: `O1p_N90` = `검색결과_oracle_page_잡음_90`, `T2MR_N90` = `검색결과_T2_잡음_90` + `판본_A규칙_잡음_90`
- 조항 단위 잡음 오라클은 `검색결과_oracle_잡음_90`(접두 page 없음)

## 3. 형식 30 (`QUESTIONS = 형식문항_30.jsonl`, `QSET = "format30"`, `MAX_TOKENS = 2048`)

| EXP | RETRIEVAL | 상태 |
|---|---|---|
| O1p_F30 | 검색결과_oracle_page_형식_30 | 지금 가능 |
| T2M_F30 | (A가 형식 30 검색 결과를 주면 `convert_a.py`로 변환) | A 대기 |

- 서술형(300~500자)이 '답' 칸에 들어가서 출력이 길다. 그래서 2048.
- 채점은 C가 한다(형식 준수율, 답 정확도). 우리 채점 칸에서는 상태·판본만 참고로 나온다.

## 4. 응답 시간 (최종 후보 모델만)

`EXP = "LAT_150"`, T2MR_150과 같은 설정, `CONCURRENCY = 1`, `LIMIT = 30`.

## 5. A가 새 검색 결과를 주면

```bash
python convert_a.py <A의 retrieval_XXX_V2.jsonl> data/검색결과_T2_XXX.jsonl data/판본_A규칙_XXX.jsonl data/<질문>.jsonl
```

- 메모 있는 판을 넣는다(없는 판은 필요 없음. 메모 켬/끔은 `USE_MEMO`로).
- 마지막 인자로 질문 파일을 주면 A가 쓴 질문이 우리 질문과 같은지 확인해 준다.

## 6. 채점 (채점 칸 맨 위)

```python
RESULT_FILES = [<돌린 결과 파일들>]
ANSWERS = "data/개발정답_150_N90_F30.csv"
MAIN_EXP = "O1p_150"   # 유형별 표·혼동표를 볼 실험. 잡음 비교 때는 "O1p_N90"
```

## 7. 알아 둘 것

- 잡음 90은 C 검수판(11/19)이다. 13문항(N011, N017, N034~N039, N052~N054, N077, N086)의 말투·압박 문장이 바뀌었다. 정답은 같다.
- A의 잡음 검색 결과는 바뀌기 전 질문으로 만든 것이라 이 13문항만 질문이 다르다. 영향은 작지만, A가 새 잡음 파일로 다시 뽑아 주면 `convert_a.py`로 바꿔 끼운다.
- 판본 파일은 A 규칙 g2.2다(개발 150 150/150, 잡음 90 90/90). dev150을 보고 고친 규칙이라 이 점수는 낙관적이다. 실제 성능은 봉인 문항으로 본다.
- 프롬프트 예시 3개 중 2개(가능·무관)는 C 확인 대기다. C가 안 된다고 하면 `EXAMPLES = "예시_p2_C확인만.json"`(C가 준 추가 확인 예시 하나)으로 바꾸고, 그 전에 돌린 결과는 다시 돌린다.
