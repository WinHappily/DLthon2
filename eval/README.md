# eval — 처음 보는 질문 평가 (C · 이승화)

스크립트는 실행기 `run_all.py`와 같은 폴더에서 돌아가야 해서 `../serving/`에 있다. 이 문서는 그 스크립트들의 설명이다.

| 파일 | 역할 |
| --- | --- |
| `공개_실행.sh`, `채점_PUB.py` | 공개 100 실행(V2 · V3)과 채점: 판정 상태 40문항, 판본 13문항, 수치 · 선택 · 예아니오 형식 답 41문항, 근거 쪽 |
| `봉인_실행.sh`, `채점_봉인.py` | 봉인 50 실행과 채점(질문 · 정답 파일은 팀장만 보관) |
| `무규칙_봉인.sh` | 판본 규칙을 끈 분석 실행: 판정 메모의 판본 줄을 지우고 판본 고정을 끔 |

원칙: 최종 조합을 노션에 먼저 기록한 뒤 한 번씩만 실행하고, 결과를 보고 모델 · 규칙 · 정답을 고치지 않았다. 평가 키트와 봉인 문항은 저장소에 넣지 않았다.
